# מה נבדק לפני המסירה

סביבת העבודה שבה הפרויקט נבנה **לא הייתה מחוברת לאתר החבילות npm**. לכן לא ניתן היה להתקין שם את התלויות (Express, Prisma ועוד), ולא להריץ את השרת או את הבדיקות האוטומטיות.

## ✅ נבדק בפועל
| בדיקה | תוצאה |
|---|---|
| קובץ ה־Migration הורץ על PostgreSQL 16 אמיתי | 6 טבלאות, 11 אינדקסים ו־10 אילוצים נוצרו ללא שגיאות |
| אילוצי מסד הנתונים | מחיר 0 נדחה, משלוח בלי כתובת נדחה |
| התאמה בין `schema.prisma` לטבלאות שנוצרו | כל העמודות והאפשרות לערך ריק תואמות |
| כללי הוולידציה (Zod 3.25) הורצו על דוגמאות תקינות ושגויות | כל ההודעות בעברית חזרו כמצופה (הרשמה, התחברות, מוצר, הזמנה, יצירת קשר, סינון) |
| פונקציות תאריכים | "היום/מחר" לפי שעון ישראל, ו־31 בפברואר נדחה |
| `docs/openapi.json` נוצר מהקוד | 24 Endpoints, כל ההפניות (`$ref`) תקינות |
| ניתוח תחבירי של כל קובצי TypeScript | 0 שגיאות תחביר |

## ⏳ לא נבדק כאן, וצריך להריץ פעם אחת
| בדיקה | פקודה |
|---|---|
| התקנת תלויות | `npm install` |
| בדיקת Prisma | `npm run prisma:validate` |
| בדיקת טיפוסים (TypeScript strict) | `npm run typecheck` |
| בנייה | `npm run build` |
| בדיקות אוטומטיות (89 בדיקות ב־7 קבצים) | `npm test` (ראי README) |
| הכל ביחד | `npm run check` |

גם הבנייה ב־Render (`npm install` ו־`npm run build`) מבצעת התקנה, בדיקת טיפוסים ובנייה. אם יש בעיה, היא תופיע ב־Logs.

הקובץ `package-lock.json` ייווצר אוטומטית בהרצה הראשונה של `npm install`. כדאי להעלות אותו ל־GitHub אחרי שהוא נוצר.
