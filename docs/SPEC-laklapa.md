# מסמך אפיון — Laklapa

גרסה 2 — כולל: ניהול משתמשים, פרטי לקוחות, יצירת מעצבות, הסרת יצירת קשר מהמעצבת.

---

## א. תיאור הפרויקט

**שם:** Laklapa — אתר קטלוג והזמנות של מעצבת פרחים ומתנות.

**מטרה:** לאפשר ללקוחות לצפות בקטלוג, להזמין כמה מוצרים בהזמנה אחת עם התאמה אישית (צבע מועדף, הערות, כרטיס ברכה) ולעקוב אחר ההזמנות. המעצבת מנהלת את הקטלוג, ההזמנות, הלקוחות וההודעות.

**משתמשים:**

| תפקיד | תיאור |
|---|---|
| אורחת (לא מחוברת) | צופה בקטלוג, שולחת הודעת יצירת קשר, נרשמת |
| לקוחה (CUSTOMER) | נרשמת בעצמה, מזמינה, עוקבת אחר הזמנותיה ומבטלת אותן |
| מעצבת (ADMIN) | מנהלת האתר. המעצבת הראשונה נוצרת מראש בהגדרות השרת; מעצבות נוספות נוצרות רק על ידי מעצבת מחוברת |

## ב. רשימת מסכים

### מסכים ציבוריים (אורחת ולקוחה)

1. **קטלוג (דף הבית)** — מוצרים זמינים בלבד, מהחדש לישן. כפתורי קטגוריות לסינון. לכל מוצר: תמונה, שם, מחיר.
2. **פרטי מוצר** — תמונה, שם, תיאור, מחיר, קטגוריה. בחירת כמות, צבע מועדף, הערות ← "הוספה לסל".
3. **סל קניות** — רשימת המוצרים שנבחרו, שינוי כמות / הסרה, סכום משוער. הסל נשמר בצד ה־React עד לשליחת ההזמנה.
4. **התחברות** — אימייל וסיסמה.
5. **הרשמה** — שם מלא, אימייל, טלפון, סיסמה. יוצרת לקוחה בלבד.
6. **צרי קשר** — שם, אימייל, טלפון (לא חובה), נושא, הודעה. ללקוחה מחוברת הפרטים ממולאים מראש.
   **המסך והקישור אליו אינם מוצגים כלל למעצבת מחוברת.**

### מסכים ללקוחה מחוברת

7. **השלמת הזמנה** — אופן קבלה (משלוח / איסוף עצמי), כתובת (במשלוח), שם המקבל/ת, טלפון, תאריך מבוקש, נוסח כרטיס ברכה ← "שליחת הזמנה".
8. **ההזמנות שלי** — רשימת הזמנות: מספר, תאריך, סכום, סטטוס.
9. **פרטי הזמנה** — כל המוצרים וההתאמות האישיות. כפתור "ביטול הזמנה" מוצג רק בסטטוס "התקבלה".

### מסכים למעצבת

10. **ניהול מוצרים** — כל המוצרים כולל מוסתרים; הוספה, עריכה, הסתרה / הצגה.
11. **טופס מוצר** — שם, תיאור, מחיר, קטגוריה, קישור לתמונה, זמין/מוסתר.
12. **ניהול קטגוריות** — הוספה, עריכה, מחיקה (רק קטגוריה ללא מוצרים).
13. **ניהול הזמנות** — כל ההזמנות; סינון לפי סטטוס וטווח תאריכים; חיפוש לפי שם מקבל/ת או מספר הזמנה.
14. **פרטי הזמנה (מעצבת)** — כל הפרטים כולל פרטי הלקוחה; שינוי סטטוס.
15. **הודעות** — הודעות יצירת קשר; סינון טופלה / לא טופלה; סימון כטופלה.
16. **ניהול משתמשים** — שתי לשוניות:
    - **לקוחות** — שם, אימייל, טלפון, תאריך הרשמה, מספר הזמנות; חיפוש לפי שם / אימייל / טלפון; לחיצה ← פרטי לקוחה.
    - **מעצבות** — רשימת המעצבות + כפתור "יצירת מעצבת חדשה" (שם מלא, אימייל, טלפון, סיסמה).
17. **פרטי לקוחה** — פרטי הלקוחה ורשימת הזמנותיה (לחיצה ← פרטי הזמנה).

> לתפריט המעצבת אין קישור ל"צרי קשר" ולא ל"סל קניות".

## ג. הרשאות

| פעולה | אורחת | לקוחה | מעצבת |
|---|:-:|:-:|:-:|
| צפייה בקטלוג ובקטגוריות | ✅ | ✅ | ✅ |
| צפייה במוצרים מוסתרים | ❌ | ❌ | ✅ |
| הרשמה | ✅ | – | – |
| התחברות | ✅ | ✅ | ✅ |
| שליחת הודעת יצירת קשר | ✅ | ✅ | ❌ (לא מוצג, וגם חסום בשרת) |
| יצירת הזמנה | ❌ | ✅ | ❌ |
| צפייה בהזמנות | ❌ | רק שלה | כולן |
| ביטול הזמנה | ❌ | רק שלה, בסטטוס "התקבלה" | ✅ דרך שינוי סטטוס |
| שינוי סטטוס הזמנה | ❌ | ❌ | ✅ |
| ניהול מוצרים וקטגוריות | ❌ | ❌ | ✅ |
| צפייה בהודעות וטיפול בהן | ❌ | ❌ | ✅ |
| צפייה בלקוחות ובפרטיהן | ❌ | ❌ | ✅ |
| יצירת מעצבת חדשה | ❌ | ❌ | ✅ |

**סטטוסי הזמנה:**
התקבלה (RECEIVED) ← בהכנה (IN_PREPARATION) ← נשלחה / מוכנה לאיסוף (SHIPPED) ← נמסרה (DELIVERED).
בוטלה (CANCELLED) — אפשרי מכל סטטוס שאינו "נמסרה".

## ד. תכנון מסד הנתונים (PostgreSQL + Prisma)

### 1. User — משתמשות

| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | Int | ✅ | **PK**, אוטומטי |
| fullName | String | ✅ | 2–60 תווים |
| email | String | ✅ | **ייחודי**, אימייל תקין, נשמר באותיות קטנות |
| phone | String | ✅ | טלפון ישראלי תקין |
| passwordHash | String | ✅ | Hash (bcrypt) בלבד; לעולם לא מוחזר ב־API |
| role | Enum: CUSTOMER / ADMIN | ✅ | ברירת מחדל CUSTOMER |
| createdAt, updatedAt | DateTime | ✅ | אוטומטי |

### 2. Category — קטגוריות

| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | Int | ✅ | **PK** |
| name | String | ✅ | **ייחודי**, 2–40 תווים |
| createdAt | DateTime | ✅ | אוטומטי |

### 3. Product — מוצרים

| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | Int | ✅ | **PK** |
| name | String | ✅ | 2–80 תווים |
| description | String | ✅ | 10–1000 תווים |
| price | Decimal(10,2) | ✅ | גדול מ־0 |
| imageUrl | String | ✅ | כתובת URL תקינה |
| categoryId | Int | ✅ | **FK** ← Category |
| isActive | Boolean | ✅ | ברירת מחדל true (זמין) |
| createdAt, updatedAt | DateTime | ✅ | אוטומטי |

### 4. Order — הזמנות

| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | Int | ✅ | **PK**, משמש גם כמספר הזמנה |
| userId | Int | ✅ | **FK** ← User; נקבע לפי ה־Token |
| status | Enum (5 סטטוסים) | ✅ | ברירת מחדל RECEIVED |
| deliveryMethod | Enum: DELIVERY / PICKUP | ✅ | |
| deliveryAddress | String | במשלוח | חובה כאשר deliveryMethod = DELIVERY |
| recipientName | String | ✅ | 2–60 תווים |
| recipientPhone | String | ✅ | טלפון תקין |
| requestedDate | Date | ✅ | לא מוקדם ממחר |
| greetingText | String | ❌ | עד 300 תווים |
| totalAmount | Decimal(10,2) | ✅ | **מחושב בשרת** |
| createdAt, updatedAt | DateTime | ✅ | אוטומטי |

### 5. OrderItem — מוצרים בהזמנה

| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | Int | ✅ | **PK** |
| orderId | Int | ✅ | **FK** ← Order (נמחק יחד עם ההזמנה) |
| productId | Int | ✅ | **FK** ← Product |
| quantity | Int | ✅ | 1–20 |
| preferredColor | Enum: WHITE / PINK / RED / YELLOW / PURPLE / MIXED | ✅ | |
| notes | String | ❌ | עד 300 תווים |
| unitPrice | Decimal(10,2) | ✅ | המחיר ברגע ההזמנה |

הזמנה חייבת לכלול 1–20 פריטים.

### 6. ContactMessage — הודעות יצירת קשר

| שדה | טיפוס | חובה | הערות |
|---|---|:-:|---|
| id | Int | ✅ | **PK** |
| userId | Int | ❌ | **FK** ← User, רק אם השולחת לקוחה מחוברת |
| name | String | ✅ | 2–60 תווים |
| email | String | ✅ | אימייל תקין |
| phone | String | ❌ | |
| subject | String | ✅ | 2–100 תווים |
| message | String | ✅ | 5–2000 תווים |
| isHandled | Boolean | ✅ | ברירת מחדל false |
| createdAt | DateTime | ✅ | אוטומטי |

ההודעות נשמרות במסד הנתונים ומוצגות במסך "הודעות". **אין שליחת מייל.**

### קשרים

- Category 1 ← N Product
- User 1 ← N Order
- Order 1 ← N OrderItem
- Product 1 ← N OrderItem
- User 1 ← N ContactMessage (לא חובה)

### כללי מחיקה

- מוצר אינו נמחק — רק מוסתר (isActive = false).
- קטגוריה שיש בה מוצרים אינה נמחקת (409).
- משתמשות אינן נמחקות במערכת.

## ה. Endpoints

כל הכתובות מתחילות ב־`/api`.
🔓 ציבורי · 👤 לקוחה מחוברת · 👑 מעצבת

### מערכת ואימות

| Method | URL | תיאור | הרשאה |
|---|---|---|---|
| GET | /health | תקינות השרת והחיבור למסד | 🔓 |
| POST | /auth/register | הרשמת לקוחה. Body: `fullName, email, phone, password` ← `{ token, user }` | 🔓 |
| POST | /auth/login | התחברות. Body: `email, password` ← `{ token, user }` | 🔓 |
| GET | /auth/me | פרטי המשתמשת המחוברת | 👤👑 |

### קטגוריות

| Method | URL | תיאור | הרשאה |
|---|---|---|---|
| GET | /categories | כל הקטגוריות | 🔓 |
| POST | /categories | הוספה. Body: `name` | 👑 |
| PUT | /categories/:id | עריכה. Body: `name` | 👑 |
| DELETE | /categories/:id | מחיקה; 409 אם יש מוצרים | 👑 |

### מוצרים

| Method | URL | תיאור | הרשאה |
|---|---|---|---|
| GET | /products?categoryId= | מוצרים זמינים, סינון לפי קטגוריה (לא חובה). למעצבת: `includeInactive=true` | 🔓 |
| GET | /products/:id | פרטי מוצר; מוסתר ← 404 למי שאינה מעצבת | 🔓 |
| POST | /products | הוספה. Body: `name, description, price, imageUrl, categoryId, isActive` | 👑 |
| PUT | /products/:id | עריכה, כולל הסתרה/הצגה דרך `isActive` | 👑 |

### הזמנות

| Method | URL | תיאור | הרשאה |
|---|---|---|---|
| POST | /orders | יצירת הזמנה. Body: `items[] { productId, quantity, preferredColor, notes }`, `deliveryMethod, deliveryAddress, recipientName, recipientPhone, requestedDate, greetingText` | 👤 |
| GET | /orders/my | הזמנות הלקוחה המחוברת | 👤 |
| GET | /orders/:id | פרטי הזמנה; הזמנה של לקוחה אחרת ← 404 | 👤👑 |
| PATCH | /orders/:id/cancel | ביטול על ידי הלקוחה, רק בסטטוס RECEIVED; אחרת 409 | 👤 |
| GET | /orders?status=&from=&to=&search= | כל ההזמנות עם סינון וחיפוש | 👑 |
| PATCH | /orders/:id/status | שינוי סטטוס. Body: `status` | 👑 |

### ניהול משתמשים

| Method | URL | תיאור | הרשאה |
|---|---|---|---|
| GET | /users?role=CUSTOMER&search= | רשימת משתמשות לפי תפקיד (CUSTOMER / ADMIN), חיפוש לפי שם / אימייל / טלפון, כולל מספר הזמנות | 👑 |
| GET | /users/:id | פרטי משתמשת והזמנותיה | 👑 |
| POST | /users/admins | יצירת מעצבת חדשה. Body: `fullName, email, phone, password` | 👑 |

### יצירת קשר

| Method | URL | תיאור | הרשאה |
|---|---|---|---|
| POST | /contact | שליחת הודעה. Body: `name, email, phone, subject, message`. מעצבת מחוברת ← 403 | 🔓👤 |
| GET | /contact?isHandled= | רשימת הודעות עם סינון | 👑 |
| PATCH | /contact/:id | Body: `isHandled` | 👑 |

### קודי שגיאה

| קוד | משמעות |
|---|---|
| 400 | נתונים לא תקינים (פירוט לפי שדה) |
| 401 | לא מחוברת / Token חסר, לא תקין או שפג תוקפו |
| 403 | אין הרשאה לפעולה |
| 404 | לא נמצא |
| 409 | התנגשות (אימייל קיים, ביטול לא אפשרי, קטגוריה עם מוצרים) |
| 500 | שגיאת שרת |

כל שגיאה מוחזרת בפורמט אחיד עם הודעה בעברית.

### אבטחה

- סיסמאות נשמרות כ־Hash באמצעות bcrypt.
- JWT בתוקף ליום אחד (ניתן לשינוי במשתנה סביבה).
- זהות המשתמשת נקבעת רק לפי ה־Token.
- סיסמאות, Hash וסודות לעולם אינם מוחזרים בתשובות.
- CORS ניתן להגדרה במשתנה סביבה.

## ו. התאמה לדרישות החובה

| דרישה | מימוש |
|---|---|
| התחברות | הרשמה, התחברות ו־JWT |
| שני סוגי משתמשים | לקוחה ומעצבת עם הרשאות שונות |
| אובייקט מרכזי עם 5+ שדות | מוצר: שם, תיאור, מחיר, תמונה, קטגוריה, זמינות |
| רשימת רשומות | קטלוג, ההזמנות שלי, ניהול הזמנות, לקוחות, הודעות |

| עריכת רשומה | מוצר, קטגוריה, סטטוס הזמנה, סימון הודעה |
| שדה בחירה | קטגוריה, סטטוס הזמנה, צבע מועדף, אופן קבלה |
| חיפוש / סינון / מיון | סינון קטלוג לפי קטגוריה; סינון וחיפוש הזמנות ולקוחות |
| מסד נתונים אמיתי | PostgreSQL עם Prisma, 6 טבלאות עם קשרים |
